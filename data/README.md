# data/: local data (gitignored)

Everything in this folder except this README is ignored by Git.

- `videos/`: sample room videos
- `runs/`: pipeline outputs (frames, checkpoints, splats, metrics)
- `minio/`: MinIO object storage files (default `MINIO_DATA_DIR`)

Room videos are **personal data**: never commit them or upload them to third-party services without client approval.
